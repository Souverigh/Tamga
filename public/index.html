В режиме «Только текст» файл обрабатывается прямо в браузере и никуда не отправляется. В режиме «Текст + поля» файл отправляется на наш сервер и дальше в Gemini API для распознавания — на сервере не сохраняется, используется только для одного запроса. Качество распознавания зависит от чёткости скана и почерка/шрифта в оригинале.
